# Bot WhatsApp — YONIF TP 953/HARIMAU RAWA

## Fitur
- WhatsApp Web + QR Code (Baileys)
- Pesan apa pun dari pengguna -> pesan pembuka
- Ketik MENU -> menu layanan terpisah
- Menu 01–08
- Alur 08 Pengawasan Anggota: nama pelapor, waktu/lokasi, identitas anggota, uraian, bukti, nomor kontak
- Konfirmasi digantikan pencatatan otomatis setelah data lengkap
- Nomor tiket otomatis dan cek status sederhana
- Database lokal `data/pengaduan.json`

## Instalasi
1. Install Node.js 18+.
2. Buka terminal pada folder bot.
3. Jalankan `npm install`.
4. Jalankan `npm start`.
5. Scan QR yang tampil di terminal menggunakan WhatsApp > Perangkat tertaut.

Catatan: Jangan hapus folder `auth_info` setelah berhasil login.
